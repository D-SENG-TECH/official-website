# 繁中文案改版（首頁、關於我們、關係企業產品頁）

## 10:40 — 多段文字仍存成單一字串，用空行分段

**決策**：業主提供的新文案多為兩到三段、並有粗體重點。i18n 的欄位維持字串，段落之間用空行（`\n\n`）分隔，範本以 `split("\n\n")` 逐段輸出，粗體直接寫 `<strong>` 並以 `safe` 輸出。

**為什麼**：`scripts/check-i18n.js` 要求四個語系的鍵與陣列長度完全一致。把欄位改成陣列，其他三個語系在翻譯完成前就會結構不符；維持字串則舊文案照常顯示，翻譯可以之後一次補上。

**替代方案**：改成段落陣列（結構較乾淨，但要同步改四個語系，且每段數量必須相同）。

**結論**：首頁的故事與關係企業段落、關於我們的兩條沿革、公司簡介頁的沿革都用同一種寫法。

## 11:10 — 產品名稱統一與刪除一個產品項目

**決策**：智能焊接相關名稱在繁中全站統一為「智能視覺手臂」；關係企業產品頁的「彎頭管件」改為「彎頭與管配件（Elbow and Fittings）」，「鍛造與微型管件」從清單、照片與 3D 產線標籤移除，「伸縮囊閥」改為「波紋管閥」。

**為什麼**：業主指定用詞。刪除清單項目會改變陣列長度，所以四個語系的同一個項目一併刪除、英文標籤一併更新；其餘翻譯留待文案定稿後處理。

**沒有動的地方**：內頁網址 `/business/smart-welding/` 維持不變，避免已分享的連結失效；3D 產線中的零件模型本身不刪，只改標籤。

## 11:20 — 沿革章節新增副標

**決策**：`about.story[]` 新增 `subtitle` 欄位，顯示在章節標題下方。四個語系都補上，以維持結構一致。

## 14:30 — AI 監測頁第三個系統畫面改為頻譜與時域波形

**決策**：原本的「30 日振動趨勢線」換成上下兩格：上方是頻譜（1×、2×、軸承外環頻率、葉片通過頻率的峰值），下方是帶有週期性衝擊的時域波形。兩者由 `screens.js` 以示意數值持續更新，軸承頻率的峰值會緩慢起伏。

**為什麼**：業主把這一步的名稱改為「頻譜時幅分析」並要求換畫面；趨勢線表達的是「總量隨時間變化」，與新名稱不符，而且第二個畫面已經在講總量連續監測。

**替代方案**：只改標題、保留趨勢線（最省事，但圖文不符）。

**結論**：圖是四個語系共用的，所以四個語系這一格的文字一起更新；初始曲線直接寫在範本裡，沒有 JavaScript 或關閉動態效果時仍看得到靜態圖。

## 14:40 — 風機示意圖隨運轉點振動

**決策**：「看不見的危險線」區塊左側是一張靜態渲染圖。讓 `sweetspot.js` 依右側曲線的振動讀數設定 CSS 變數，圖片以對應幅度抖動，軸承座位置加一層隨讀數變亮的光暈。

**為什麼**：圖說寫明與右圖連動，但原本圖片完全不動。

**替代方案**：改成即時 3D 模型（只讓機體振動、可旋轉），工程量大很多，先以圖片效果確認需求。

## 15:10 — 用字統一的基準

**決策**：全文檢查後固定以下寫法。AI 監測分三層：事業項目與內文「AI 預警與監測」、選單「AI 監測系統」、產品名「AI 智能預警系統」。其餘：感測器（不用傳感器）、智慧製造、調壓閥、氟素樹脂管、壓接式接頭、機器手臂、相機、備品、聯絡、Email、良率（Yield Rate）。破折號統一為前後加空格的「——」，數字範圍用「–」。

**為什麼**：同一顆感測器在不同頁面有兩種名稱，AI 監測的名稱更有九種寫法，讀者會以為是不同產品。

**沒有動的地方**：業主指定的「原廠」相關說法、營運項目的登記用語、「上海上茂辦公室」維持原文，待業主確認。

**連帶**：產品動畫頁的繁中旁白稿改用新名稱，並重新產生該段語音。

## 16:40 — 3D 展間放回首頁 hero

**決策**：展間的標記與腳本抽成 `src/_includes/hero3d.njk`，首頁與 `/temp/showroom/` 都引用同一份；首頁原本的靜態照片 hero 移除，照片改當沒有 WebGL 時的備援背景。

**為什麼**：業主確認要把展間放回首頁。兩頁共用一份，之後調整只改一處；暫存頁保留，方便單獨分享（仍需密碼、不被收錄）。

**連帶**：展間裡的風機不再顯示振動感測器與脈衝環（`showroom.js` 傳 `noSensors` 給場景），捲動版的產品動畫頁不受影響。智能視覺手臂內頁的主圖改為同一套 3D 焊接場景。
